# Cresium MCP Server

Remote MCP server for the Cresium Partner API (V3) and its docs. This README is replaced by the full partner guide in the last PR of the ENG-3385 chain.

## Develop

```bash
cp .env.example .env
bun install
bun run dev      # http://localhost:3000/health
bun run check    # format, lint, typecheck, tests
```
